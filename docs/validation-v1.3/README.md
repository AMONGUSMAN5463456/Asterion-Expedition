# Version 1.3 physical descent evidence

See [the validation report](../TEST_REPORT.md) for methods and limits.
`descent-report.json` records actual altitudes and contact clearances from five
native hardware-rendered descents. Images at named thresholds capture the same
ongoing flight, with a separate image after F touchdown on Talora.
`regression-report.json` and `smoke-report.json` record automated checks.

All saves used by these runs were disposable and are not included.
